# Kyte on the HOL registry

[HOL (Hashgraph Online)](https://hol.org) runs a cross-registry directory of AI agents and MCP servers, searchable from
Claude, Cursor and other clients through their broker. Kyte lists its MCP server there as an HCS-11 profile with a
Universal Agent ID (UAID), so any HOL-connected agent can discover and call it without knowing our URL.

## What is published

- Profile: generated by `scripts/hol/profile.mjs` from the live tool catalogue at `https://kyte.sh/api/mcp`.
- Endpoint: MCP streamable HTTP, no auth, read and prepare tools only.
- Ownership proof: DNS. A TXT record `_hedera.kyte.sh` whose value is Kyte's Hedera account id (HCS-11 `verification.type = dns`).

## Steps

1. Hedera account and HOL key: create or use a Hedera mainnet account for Kyte; sign in at https://hol.org/registry and
   create a Registry Broker API key in the billing portal. Base registration is in their free tier; the quote confirms it.
2. DNS: add TXT `_hedera.kyte.sh` = `0.0.<account>`.
3. Generate and register:
   ```bash
   cd scripts/hol && pnpm install
   HEDERA_ACCOUNT_ID=0.0.xxxx node profile.mjs
   REGISTRY_BROKER_API_KEY=… node register.mjs --quote        # expect 0 shortfall
   REGISTRY_BROKER_API_KEY=… node register.mjs --register     # prints the UAID, records it below
   ```
4. Optional: "verified and featured" at https://hol.org/registry/feature-your-agent; Plugins Registry listing at
   https://hol.org/plugins (scanner evidence plus owner verification).

Updates (new tools, description) go through `client.updateAgent(uaid, payload)` with a regenerated profile.
